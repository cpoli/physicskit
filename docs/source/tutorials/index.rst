Tutorials
=========

Long-form, narrative walkthroughs. Each one builds up a topic step by
step with the public API and checks the numbers it produces against
known closed-form or published results. For short, single-topic scripts,
see the :doc:`example gallery </examples/index>`.

Start with :doc:`units_and_conventions`: it explains the natural unit
system each subpackage computes in, and how to convert results to SI.
