Ginzburg-Landau Theory
----------------------

The 1950 phenomenological free-energy theory of superconductivity: the
equilibrium order parameter, the coherence length and penetration depth it
sets, the Ginzburg-Landau parameter that separates Type I from Type II
superconductors, and the exact order-parameter healing profile at a
boundary.
