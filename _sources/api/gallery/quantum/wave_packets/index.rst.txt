Wave packets
------------

Non-stationary wave dynamics: electron twin-slit interference built up
one detection at a time (with an animated view of the packet spreading),
quantum revivals in an infinite well, Ehrenfest's theorem in an
anharmonic potential, and a phase-colored
animation of double-well tunneling.
