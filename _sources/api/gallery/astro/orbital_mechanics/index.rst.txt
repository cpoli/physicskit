The modern version of the last step of that problem -- given a single Cartesian state (position and velocity) at one instant, recover the six classical orbital elements (a, e, i, \Omega, \omega, \nu) -- is exactly what orbital_elements_from_state does; state_from_orbital_elements is its inverse.
