Quantum fields
-----------------

Gross-Pitaevskii mean-field theory for a trapped, rotating Bose-Einstein
condensate: quantized vortex detection, a bound vortex-antivortex pair with
canceling net winding, ground-state relaxation, the critical rotation
frequency for vortex nucleation, a vortex genuinely precessing in real time,
self-focusing wave collapse, and the Casimir vacuum force.
