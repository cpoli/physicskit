Entanglement and topology
--------------------------

Bell/EPR spin correlations and the CHSH inequality, the Aharonov-Bohm
effect (a purely topological consequence of the vector potential),
Bloch-sphere qubit dynamics (Larmor precession and an animated Rabi
oscillation), the dynamical generation of entanglement between two
qubits coupled by an Ising interaction, and why no fixed unitary can
clone an arbitrary qubit state (the no-cloning theorem).
