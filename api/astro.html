physicskit.astro#

physicskit.astro hub · History · Examples · API reference

physicskit.astro: stellar structure, N-body dynamics, orbital mechanics, and galactic dynamics.

Uses gravitational units with \(G=1\) by default throughout (every function that needs it accepts G as a keyword argument), the same convention physicskit.relativity uses for its own geometrized units.

  • physicskit.astro.stellar_structure – polytropic stellar models via the Lane-Emden equation, the Chandrasekhar mass limit, and the main-sequence mass-luminosity relation.

  • physicskit.astro.nbody – direct-summation N-body gravitational dynamics with a symplectic leapfrog integrator.

  • physicskit.astro.orbital_mechanics – classical orbital elements, state-vector conversion, and Hohmann transfers.

  • physicskit.astro.galactic_dynamics – the NFW dark matter halo profile and the rotation curves it produces.

  • physicskit.astro.sph – smoothed-particle hydrodynamics in one dimension, checked on Sod’s shock tube.

  • physicskit.astro.radiative_transfer – the grey plane-parallel atmosphere: the Eddington approximation, the exact Hopf function and limb darkening.

  • physicskit.astro.visualizers – N-body, Lane-Emden, and rotation-curve plots.

class physicskit.astro.GreyAtmosphere(n_streams=32)[source]#

Bases: object

Exact grey atmosphere in Chandrasekhar’s \(n\)-stream discrete-ordinates approximation.

With Gauss-Legendre nodes \(\pm\mu_i\) and weights \(a_i\) (\(i = 1..n\)), the intensities are

\[I(\tau, \mu_i) = \tfrac34 F\left[\tau + \mu_i + Q + \sum_{\alpha=1}^{n-1} \frac{L_\alpha e^{-k_\alpha\tau}}{1 + k_\alpha\mu_i}\right],\]

where the \(k_\alpha\) are the positive roots of \(\sum_i a_i/(1 - k^2\mu_i^2) = 1\) and \(Q\), \(L_\alpha\) follow from no incoming radiation at \(\tau = 0\). The Hopf function is \(q(\tau) = Q + \sum_\alpha L_\alpha e^{-k_\alpha\tau}\).

Parameters:

n_streams (int) – Number \(n\) of directions per hemisphere.

Variables:

  • Q (float) – \(q(\infty)\), which tends to Hopf’s 0.710446 as \(n\) grows.

  • L (k,) – Decay constants and amplitudes of the transient terms.

Examples

>>> atm = GreyAtmosphere()
>>> round(float(atm.hopf(0.0)), 6)  # 1/sqrt(3) in every approximation
0.57735
>>> round(atm.Q, 4)
0.7104

physicskit.astro.lane_emden(n, xi_max=1000.0, n_points=2000)[source]#

Integrate the Lane-Emden equation for a polytrope of index n.

\[\frac{1}{\xi^2}\frac{d}{d\xi}\left(\xi^2\frac{d\theta}{d\xi}\right) + \theta^n = 0, \qquad \theta(0)=1,\ \theta'(0)=0\]

the dimensionless hydrostatic-equilibrium profile of a self-gravitating sphere with equation of state \(P=K\rho^{1+1/n}\).

Parameters:

  • n (float) – Polytropic index.

  • xi_max (float, default=1000.0) – Upper integration bound. Integration normally stops earlier, at the surface; the default is large enough to reach it for every \(n \le 4.9\) (\(\xi_1 \approx 171\) there, diverging as \(n \to 5\)). For \(n \ge 5\) there is no surface and the profile is returned out to xi_max.

  • n_points (int, default=2000) – Number of points to sample the returned arrays at.

Returns:

  • xi (ndarray) – Dimensionless radius, from just above 0 to the surface (the first zero of \(\theta\)) or, if none was found, to xi_max.

  • theta (ndarray) – The Lane-Emden function \(\theta(\xi)\). theta[-1] == 0 exactly when the surface was reached.

Examples

>>> xi, theta = lane_emden(0.0)
>>> round(float(xi[-1]), 3)  # exact analytic surface is sqrt(6)
2.449
>>> xi, theta = lane_emden(4.0)
>>> round(float(xi[-1]), 3)  # tabulated xi_1 for n=4
14.972

Smoothed-particle hydrodynamics (SPH) in one dimension.

SPH represents a gas by particles of fixed mass \(m\) that move with the flow (Lucy, Astron. J. 82, 1013 (1977); Gingold and Monaghan, MNRAS 181, 375 (1977)). Every field is a kernel-weighted sum over neighbours; the density is

\[\rho_i = \sum_j m_j W(x_i - x_j, h_i),\]

and the Euler equations become ordinary differential equations for the particles (Monaghan, Annu. Rev. Astron. Astrophys. 30, 543 (1992)),

\[\frac{dv_i}{dt} = -\sum_j m_j\left(\frac{P_i}{\rho_i^2} + \frac{P_j}{\rho_j^2} + \Pi_{ij}\right)\partial_i W_{ij}, \qquad \frac{du_i}{dt} = \frac12\sum_j m_j\left(\frac{P_i}{\rho_i^2} + \frac{P_j}{\rho_j^2} + \Pi_{ij}\right) v_{ij}\,\partial_i W_{ij},\]

with \(P = (\gamma - 1)\rho u\), the cubic-spline kernel, and Monaghan’s artificial viscosity \(\Pi_{ij}\) to capture shocks. Because the particles follow the mass, resolution concentrates where the gas is dense, which is why SPH became the standard method for star formation, galaxy mergers and cosmological gas. SPH1D evolves these equations, and SPH1D.sod_shock_tube() sets up Sod’s test problem.

Grey radiative transfer in a plane-parallel stellar atmosphere.

Radiation crossing a stellar atmosphere obeys, at optical depth \(\tau\) and direction cosine \(\mu\),

\[\mu\frac{dI}{d\tau} = I - S.\]

For a grey opacity (independent of frequency) in radiative equilibrium the source function equals the mean intensity, \(S = J\), and the flux \(F = \sigma T_{\text{eff}}^4\) is constant with depth. The solution is (Milne 1921; Hopf 1930)

\[T^4(\tau) = \tfrac34 T_{\text{eff}}^4\,[\tau + q(\tau)],\]

where the Hopf function \(q\) rises from \(1/\sqrt3\) at the surface to \(0.7104\) deep inside. Eddington’s (1926) approximation, closing the moment equations with \(K = J/3\), gives the constant \(q = 2/3\), and with it the limb darkening \(I(0, \mu)/I(0, 1) = (2 + 3\mu)/5\).

GreyAtmosphere solves the problem exactly in Chandrasekhar’s discrete-ordinates method (Astrophys. J. 100, 76 (1944); Radiative Transfer, 1950, ch. III), which converges to the exact solution as the number of streams grows and keeps \(q(0) = 1/\sqrt3\) exactly in every order.
